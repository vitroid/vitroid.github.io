Matsumoto, M., Yagasaki, T. & Tanaka, H. [GenIce](/GenIce)-core: Efficient algorithm for generation of hydrogen-disordered ice structures. J. Chem. Phys. 160, 094101 (2024) [doi:10.1063/5.0198056](https://doi.org/10.1063/5.0198056)

私たちがよく知る「氷」は、一見すると綺麗に整列した結晶のように見えますが、実は水素原子の向きがバラバラ（無秩序）に配置されているというユニークな特徴を持っています。ただし、完全に好き勝手な向きを向いているわけではなく、「アイスルール」と呼ばれるルール（1つの酸素原子に対して水分子を作る2本の強結合と、隣と繋がる2本の弱結合があるという規則）を守らなければなりません。

この「ルールを守りつつランダムな配置を作る」作業は、コンピュータで大きな氷のモデルを作ろうとすると非常に計算が大変になります。特に、大きなサイズの氷結晶や、異物のイオンや欠陥が含まれる氷の性質を正しく予測するためには、大量の異なるランダムな氷構造を素早く用意する必要がありました ([MT2022](/MT2022), [TMY2024](/TMY2024))。

本[研究](/研究)では、イオンや欠陥を含む氷の分子構造を極めて高速に作成する新しいアルゴリズム「[GenIce](/GenIce)-core」を開発しました。このプログラムは独立したモジュールとして既存の様々な結晶生成ソフトに簡単に組み込むことができます。これにより、これまで計算コストの面で諦めていた超巨大なスケールでの氷の分子シミュレーションが可能になり、氷の不思議な物理的性質の解明が一気に進むと期待されています。

## Abstract

氷は無秩序性を含んでいるという点で通常の結晶とは異なっており、アンサンブル平均に基づく統計的取り扱いが不可欠です。氷の構造は「アイスルール」として知られるトポロジカルな規則によって制約されており、これが氷にユニークで特異な性質をもたらしています。これらの性質は、システムのサイズが大きくなるほどより顕著になります。そのため、アイスルールを満たしつつ均一にランダムである十分に大きな結晶を大量に生成する手法が求められていました。本[研究](/研究)では、イオンや欠陥を含む氷構造を高速に生成するアルゴリズムを開発しました。このアルゴリズムは、結晶構造生成ソフトウェアに組み込み可能な独立したソフトウェアモジュールとして提供されます。これにより、従来は不可能であったスケールでの氷結晶のシミュレーションが可能となります。(Geminiによる概要の機械翻訳)

Ice is different from ordinary crystals because it contains randomness, which means that statistical treatment based on ensemble averaging is essential. Ice structures are constrained by topological rules known as the ice rules, which give them unique anomalous properties. These properties become more apparent when the system size is large. For this reason, there is a need to produce a large number of sufficiently large crystals that are homogeneously random and satisfy the ice rules. We have developed an algorithm to quickly generate ice structures containing ions and defects. This algorithm is provided as an independent software module that can be incorporated into crystal structure generation software. By doing so, it becomes possible to simulate ice crystals on a previously impossible scale.
